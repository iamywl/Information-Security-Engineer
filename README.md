## 🔒 무결성 100% 보증 체계 (Cryptographic & Binary Integrity)

본 저장소의 모든 데이터는 **4중 무결성 검증 체계**를 통해 100% 무결성을 보장합니다:

1. **암호학적 해시 검증 (SHA-256):**
   * 모든 원문 바이너리(HWP, PDF), 마크다운, JSON 데이터의 해시값이 [`CHECKSUMS.sha256`](CHECKSUMS.sha256)에 기록되어 있습니다.
   * 터미널에서 `shasum -a 256 -c CHECKSUMS.sha256` 실행 시 1비트의 손상이나 변조도 없는지 즉시 판별 가능합니다.
2. **HWP OLE 바이너리 구조 파싱:**
   * 44개 HWP 파일 전체에 대해 OLE Compound File Binary 시그니처 및 `FileHeader` 스트림 유효성을 기계적으로 검증했습니다. (100% PASS)
3. **PDF Page Stream 렌더링 및 텍스트 추출:**
   * 44개 PDF 파일 전체에 대해 EOF 손상 없이 전 페이지 렌더링 및 본문 텍스트 추출 검증을 통과했습니다. (100% PASS)
4. **실기 문항 스키마 전수 검사:**
   * 실기 29개 회차 417문항 전체에 대해 문제 번호, 지문(최소 5자 이상), 정답 누락 여부를 자동 검사하여 결함 0건을 확인했습니다. (100% PASS)
5. **상세 검증 보고서:**
   * [`무결성_검증_보고서.md`](무결성_검증_보고서.md)에서 88개 바이너리 파일과 29개 회차의 전수 SHA-256 및 감사 결과를 열람하실 수 있습니다.
