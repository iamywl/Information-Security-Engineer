# 🛡️ Information Security Engineer (정보보안기사)

> 나만의 맞춤형 **정보보안기사 필기 & 실기 전자문제집(CBT) 및 기출문제 아카이브** 프로젝트입니다.  
> **HWP/PDF 원본 바이너리 파일**과 **Markdown/JSON 정제 문서**를 명확히 분리하여, 뷰어/인쇄용 원본 보존과 웹/CBT 서비스용 데이터 활용을 동시에 극대화했습니다.

## 📊 기출문제 데이터베이스 구축 현황

### 1. 필기 기출문제 (객관식 100문항)
* **대상:** 제1회(2013년 07월) ~ 제21회(2023년 03월) *(22회부터 비공개 CBT 상설 시험으로 전환)*
* **확보 상태:** **21개 전 회차 100% 확보 완료** (누락 0개)
* **저장 분리:**
  * `필기/기출문제/hwp/` : 교사용/학생용 HWP 44개, PDF 44개 (총 88개 원본)
  * `필기/기출문제/markdown/` : 21개 회차별 마크다운 정리 문서 (`기출문제.md`)
* **상세 현황:** [`필기/기출문제/STATUS.md`](필기/기출문제/STATUS.md)

### 2. 실기 기출문제 (단답형 / 서술형 / 실무형)
* **대상:** 제1회 ~ 제29회 전 회차
* **확보 상태:** **29개 전 회차 100% 확보 완료** (누락 0개)
* **저장 분리:**
  * `실기/기출문제/markdown/` : 29개 회차 총 **417문항** (`기출복원_원문.md`, `questions.json`, `기출복원_원문.txt`)
  * `실기/기출문제/hwp/` : 원본 문서 전용 보관 디렉토리
* **상세 현황:** [`실기/기출문제/STATUS.md`](실기/기출문제/STATUS.md)
