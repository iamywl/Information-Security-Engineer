# 🛡️ Information Security Engineer (정보보안기사)

> 나만의 맞춤형 **정보보안기사 필기 & 실기 전자문제집(CBT) 및 기출문제 아카이브** 프로젝트입니다.  
> 원문 시험지(HWP, PDF) 확보부터 기출 복원 데이터 파싱, 토큰 0소모 전처리 파이프라인, CBT 서비스용 정규화 데이터베이스 구축까지 올인원으로 관리합니다.

## 📊 기출문제 데이터베이스 구축 현황

### 1. 필기 기출문제 (객관식 100문항)
* **대상:** 제1회(2013년 07월) ~ 제21회(2023년 03월) *(※ 22회부터 CBT 문제은행 방식으로 전환되어 비공개)*
* **확보 상태:** **21개 전 회차 100% 확보 완료** (누락 0개)
* **원문 파일:** 총 **88개** (교사용/학생용 HWP 44개, PDF 44개)
* **상세 현황:** [`필기/기출문제/STATUS.md`](필기/기출문제/STATUS.md)

### 2. 실기 기출문제 (단답형 / 서술형 / 실무형)
* **대상:** 제1회 ~ 제29회 전 회차
* **확보 상태:** **29개 전 회차 100% 디렉토리 및 문항 확보 완료**
* **총 복원 문항:** **417문항** (단답형, 서술형, 실무형 정답 및 해설 포함)
* **데이터 포맷:** `questions.json` (웹 서비스용), `기출복원_원문.md` (학습용 마크다운), `기출복원_원문.txt`
* **상세 현황:** [`실기/기출문제/STATUS.md`](실기/기출문제/STATUS.md)

## 💡 토큰 최적화 설계 철학
* 웹 크롤링 및 바이너리 다운로드는 Antigravity / LLM 컨텍스트를 소모하지 않는 **경량 로컬 파이썬 파이프라인(0 토큰)**으로 수행됩니다.
* 수집된 원문은 규격화된 `JSON`과 `Markdown`으로 정제되어 있어, 추후 AI 문제 생성이나 Next.js 프론트엔드 연동 시 최소한의 토큰으로 최고의 효율을 낼 수 있도록 설계되었습니다.
