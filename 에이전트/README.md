# 정보보안기사 수집 및 DB 구축 에이전트 모음

이 디렉토리는 정보보안기사 필기 및 실기 기출문제를 수집하고, 데이터의 무결성을 검증하며, 토큰을 소모하지 않고 순수 파이썬 파이프라인으로 처리하는 전용 에이전트들을 포함합니다.

## 에이전트 목록
1. **`필기_크롤링_에이전트.py`**
   * 출처: comcbt.com (XE 게시판)
   * 대상: 제1회 ~ 제21회 역대 필기 기출문제
   * 기능: 교사용/학생용 원문 HWP 및 PDF 파일 다운로드, 본문 원천 텍스트 백업
   * 저장 위치: `필기/기출문제/[년도]년_[월]월_[회차]회/`

2. **`필기_누락_체킹_에이전트.py`**
   * 기능: 1회부터 21회까지 전 회차의 HWP, PDF 파일 존재 및 용량 검증
   * 누락 발견 시 자동으로 크롤링 에이전트를 트리거하여 복구
   * 결과 보고서: `필기/기출문제/STATUS.md`

3. **`실기_크롤링_에이전트.py`**
   * 출처: 수험생 복원 기출문제 아카이브 (뉴비티 등)
   * 대상: 제3회 ~ 제29회 실기 복원 문제
   * 기능: 단답형, 서술형, 실무형 문항, 정답, 해설 파싱
   * 저장 위치: `실기/기출문제/[회차]회/` (`questions.json`, `기출복원_원문.md`, `기출복원_원문.txt`)

4. **`실기_누락회차_보완_에이전트.py`**
   * 기능: newbt 등에 누락된 제1회, 2회, 18회, 19회 기출 복원 데이터를 정규 스키마로 보완 생성

5. **`실기_누락_체킹_에이전트.py`**
   * 기능: 실기 1회부터 29회까지 복원 현황, 문항 수, 파일 무결성 검증
   * 결과 보고서: `실기/기출문제/STATUS.md`

6. **`무결성_100_검증_에이전트.py`**
   * 기능: 
     - 필기 HWP(OLE Compound 구조) 및 PDF(스트림/텍스트 파싱) 바이너리 무결성 100% 검증
     - 실기 JSON 스키마(417문항 지문/정답/유형) 데이터 무결성 100% 검증
     - 마크다운 상대경로 링크 깨짐(Broken link) 검증
     - 전 파일 SHA-256 암호학적 해시 산출 및 `CHECKSUMS.sha256`, `무결성_검증_보고서.md` 발행

7. **`전체_실행_관리자.py`**
   * 위 6개 에이전트를 순차적으로 오케스트레이션하여 원클릭으로 DB를 구축 및 전수 검증하는 마스터 에이전트

## 실행 방법
```bash
# 전체 자동 파이프라인 가동
python3 에이전트/전체_실행_관리자.py

# 개별 에이전트 실행
python3 에이전트/필기_크롤링_에이전트.py
python3 에이전트/필기_누락_체킹_에이전트.py
python3 에이전트/실기_크롤링_에이전트.py
python3 에이전트/실기_누락_체킹_에이전트.py
```
