# 🛡️ 정보보안기사 필기 자작문제 아카이브

2024~2026년 최신 보안 기술 트렌드(AI/LLM 보안, 공급망 보안, 제로트러스트, 양자내성암호) 및 개정 법령을 완벽 반영한 실전 훈련 문제입니다.  
기출문제의 **5대 Trap 설계 패턴(개념 맞바꾸기, 극성 반전, 극단어 선지, 법령 수치 변조, 관할 부처 왜곡)**을 100% 적용하여 제작되었습니다.

---

## 📂 과목별 자작문제 모음
1. **[제1과목: 시스템 보안](과목별/제1과목_시스템보안.md)**
   * 컨테이너 격리 기술(Namespaces/cgroups) 및 `--privileged` 보안 위협
   * 커널 모니터링 혁신 기술 eBPF(Extended BPF)와 보안 관제/루트킷
   * POSIX Capabilities(`CAP_NET_RAW`, `CAP_SYS_ADMIN`)와 특권 분할
2. **[제2과목: 네트워크 보안](과목별/제2과목_네트워크보안.md)**
   * NIST SP 800-207 기반 제로 트러스트 아키텍처(ZTA) 정책 엔진(PDP/PEP)
   * 차세대 전송 표준 HTTP/3 & QUIC(UDP 443)의 보안 특성과 보안 가시성 저하
   * 암호화 DNS 프로토콜인 DoH(TCP 443)와 DoT(TCP 853) 분석
3. **[제3과목: 애플리케이션 보안](과목별/제3과목_애플리케이션보안.md)**
   * OWASP Top 10 for LLM: 프롬프트 인젝션(Direct/Indirect) 및 안전하지 않은 출력 처리
   * 소프트웨어 공급망 보안을 위한 SBOM(SPDX, CycloneDX) 및 타이포스쿼팅 방어
   * 최신 API 핵심 취약점인 BOLA(Broken Object Level Authorization)
4. **[제4과목: 정보보안 일반](과목별/제4과목_정보보안일반.md)**
   * NIST 표준화 양자 내성 암호(PQC: ML-KEM, ML-DSA) 및 쇼어/그로버 알고리즘 분석
   * 기밀성과 무결성을 동시에 보장하는 인증 암호화(AEAD) AES-GCM 모드
   * 영지식 증명(ZKP)의 3대 필수 요건(완전성, 건전성, 영지식성)
5. **[제5과목: 정보보안 관리 및 법규](과목별/제5과목_정보보안관리및법규.md)**
   * 개정 개인정보 보호법: AI '자동화된 결정'에 대한 거부권 및 설명요구권 규정
   * 자율주행차/드론 등 '이동형 영상정보처리기기' 촬영 및 운영 기준(제25조의2)
   * 전체 매출액 3% 이하 과징금 체계 및 72시간 침해사고 신고 기준
