# 정보보안기사 필기

정보보안기사 필기 시험 대비를 위한 아카이브 및 학습 플랫폼입니다.

## 과목 구성 (총 5과목, 100문항, 150분)
1. **제1과목:** 시스템 보안 (20문항)
2. **제2과목:** 네트워크 보안 (20문항)
3. **제3과목:** 애플리케이션 보안 (20문항)
4. **제4과목:** 정보보안 일반 (20문항)
5. **제5과목:** 정보보안 관리 및 법규 (20문항)

## 디렉토리 안내
* `기출문제/` : 역대 공식 기출문제 원문(HWP, PDF) 및 텍스트 데이터베이스
* `제작문제/` : 자체 제작 모의고사, 변형 문제 및 핵심 요약 문제
