## 🎯 Executive Summary (핵심 분석 요약)

1. **문항 구조의 본질:** 역대 2,100문항 분석 결과, 설명형 문항의 약 60% 이상이 **부정형(옳지 않은 것, 틀린 것)**으로 출제됩니다. 출제위원은 4개 선지 중 3개를 검증된 공인 이론(옳은 지문)으로 채우고, 1개의 선지에 정교한 논리적 왜곡(Trap)을 심습니다. 따라서 **'옳은 지문 3개를 요약노트화하여 흡수하는 3배속 역발상 회독법'**이 필기 합격의 핵심 열쇠입니다.
2. **과목별 양극화 현상:**
   * **고득점 견인 과목 (제2과목 네트워크, 제4과목 정보보안 일반):** 프로토콜 메커니즘과 수학적/암호학적 원리가 명확하여 기출 3회독 시 80점 이상 확보 가능.
   * **과락 위험 과목 (제1과목 시스템, 제5과목 법규/관리):** 세부 설정 문법(PAM, umask, 레지스트리) 및 법령 수치(72시간, 1년/2년, 5년/5천만원, 과징금 3%)의 정밀 암기 부재 시 과락(40점 미만) 다발.
3. **시대별 출제 패러다임 전환:**
   * **초기 (2013~2016):** 고전 DoS(Smurf, Land), 유닉스 시스템 명령어, WEP 무선랜, 공인인증서 체계 중심.
   * **중기 (2017~2019):** OWASP 웹 취약점 세분화(Blind SQLi, CSRF), Snort 룰 문법, 망분리 규제, 전자금융감독규정.
   * **최근 (2020~2023):** ISMS-P 102개 인증기준 통합, 클라우드 보안(IaaS/PaaS/SaaS 책임공유모델, 클라우드컴퓨팅법 제25조 침해통지), 데이터 3법(가명정보 특례 처리), 전자서명법 전면개정(공인인증서 폐지), 최신 위협(SSRF, WPA3, 랜섬웨어).

## 1. 5대 과목별 핵심 출제 공식 및 킬러 문항 패턴

### 📌 제1과목: 시스템 보안 (1번 ~ 20번)
* **[공식 1] umask 권한 계산:**
  * 디렉터리 최종 권한: $777 - \text{umask}$
  * 파일 최종 권한: $666 - \text{umask의 실행권한 제외 감산}$ (파일 기본 권한은 실행비트 없는 666).
  * 예: umask 022 $\rightarrow$ 파일 644 (`rw-r--r--`), umask 027 $\rightarrow$ 파일 640 (`rw-r-----`).
* **[공식 2] 특수 권한 비트(Special Permission Bits):**
  * `SetUID (4000)`: 실행 중 파일 소유자(UID) 권한 획득 (`-rwsr-xr-x`)
  * `SetGID (2000)`: 실행 중 파일 그룹(GID) 권한 획득 (`-rwxr-sr-x`)
  * `Sticky Bit (1000)`: 디렉터리 내 파일은 소유자 및 root만 삭제 가능 (`drwxrwxrwt`, `/tmp` 디렉터리에 적용)
  * 진단 명령어: `find / -user root -perm -4000 -print`
* **[공식 3] 리눅스 4대 계정 로그 파일 매핑:**
  * `/var/run/utmp` (바이너리): 현재 시스템에 로그인한 사용자 상태 (`who`, `w`, `users`)
  * `/var/log/wtmp` (바이너리): 성공한 로그인/로그아웃 및 시스템 부팅/종료 히스토리 (`last`)
  * `/var/log/btmp` (바이너리): 실패한 로그인 시도 기록 (`lastb`)
  * `/var/log/lastlog` (바이너리): 각 사용자 계정의 최근 로그인 시간 및 호스트 (`lastlog`)
  * `/var/log/secure` (텍스트): 인증 관련 로그 (`su`, `sudo`, `ssh`)
* **[공식 4] PAM 제어 플래그(Control Flag) 동작 원리:**
  * `required`: 실패 시 나머지 모듈 계속 실행 후 최종 실패.
  * `requisite`: 실패 시 **즉시(Immediately)** 중단 및 실패 반환.
  * `sufficient`: 앞선 required 성공 및 현재 모듈 성공 시 **즉시 성공 반환**.
  * `optional`: 성공/실패가 전체 결과에 영향 없음.
* **[공식 5] Buffer Overflow 메모리 보호 3총사:**
  * **ASLR:** 스택/힙/라이브러리 주소를 매 실행마다 무작위화.
  * **DEP / NX:** 스택/힙 영역의 실행 권한을 박탈하여 쉘코드 실행 차단.
  * **Stack Canary:** Buffer와 SFP 사이에 랜덤 쿠키를 삽입하여 변조 시 프로세스 강제 종료.

### 📌 제2과목: 네트워크 보안 (21번 ~ 40번)
* **[공식 1] TCP 포트 스캔 유형별 응답 패킷 판별 공식:**
  | 스캔 유형 | 대상 포트 열림(Open) | 대상 포트 닫힘(Closed) | 핵심 특징 |
  | :--- | :---: | :---: | :--- |
  | **TCP Open Scan** | SYN/ACK $\rightarrow$ ACK 수신 | RST/ACK 수신 | 완전한 3-Way Handshake, 로그 남음 |
  | **SYN Scan (Half-Open)** | SYN/ACK 수신 $\rightarrow$ **RST 전송** | RST/ACK 수신 | 세션 미성립, Stealth 스캔 |
  | **FIN / Null / Xmas Scan** | **무응답 (No Response)** | **RST/ACK 수신** | 유닉스 RFC 793 준수 시스템 타깃 |
  * *절대 암기 공식:* 스텔스 스캔(FIN, Null, Xmas)은 **"포트가 닫혀있으면 RST가 오고, 열려있으면 무응답"**이다.
* **[공식 2] IPsec 프로토콜 및 모드 구조:**
  * **AH (프로토콜 51):** 인증 + 무결성 + 재전송 방지 (**기밀성/암호화 미제공!**).
  * **ESP (프로토콜 50):** **기밀성(암호화)** + 인증 + 무결성 + 재전송 방지 제공.
  * **전송 모드:** 원본 IP 헤더 유지, 페이로드만 보호 (Host-to-Host).
  * **터널 모드:** 원본 IP 헤더 전체를 암호화하고 **새로운 외부 IP 헤더** 추가 (VPN Gateway 간).
* **[공식 3] DoS/DDoS 공격 유형별 패킷 특성:**
  * **Smurf:** 출발지 IP 위조 + Directed Broadcast 전송 $\rightarrow$ 대량의 ICMP Echo Reply 유발.
  * **Land:** 패킷의 **출발지 IP/Port와 목적지 IP/Port를 희생자와 동일하게 조작**.
  * **Teardrop:** IP 파편화 오프셋(Offset)을 의도적으로 중첩/왜곡시켜 재조합 시 다운.
  * **SYN Flooding:** 대량의 SYN 전송 후 ACK 미전송으로 백로그 큐(Backlog Queue) 고갈.

### 📌 제3과목: 애플리케이션 보안 (41번 ~ 60번)
* **[공식 1] 웹 3대 취약점 메커니즘 및 방어 대책:**
  * **SQL Injection:** 사용자 입력값에 SQL 구문 조작 $\rightarrow$ 방어: **PreparedStatement(파라미터화된 쿼리)**
  * **XSS:** 피해자 브라우저에서 악성 자바스크립트 실행 $\rightarrow$ 방어: **HTML Entity 출력 인코딩**, `HttpOnly` 쿠키 속성
  * **CSRF:** 피해자의 권한으로 서버에 원치 않는 위조 요청 전송 $\rightarrow$ 방어: **CSRF 토큰 검증**, `SameSite` 쿠키 속성
* **[공식 2] 이메일 보안 3대 프로토콜:**
  * **SPF:** DNS TXT 레코드에 메일 발신 가능 공인 IP 대역 등록.
  * **DKIM:** 발신자가 디지털 서명을 메일 헤더에 추가, 수신자가 발신자 공개키로 서명 검증.
  * **DMARC:** SPF와 DKIM 검증 결과를 기반으로 실패 시 처리 정책(`none`, `quarantine`, `reject`) 수립.
* **[공식 3] FTP 능동(Active) vs 수동(Passive) 모드:**
  * **Active:** 클라이언트가 21번 연결 $\rightarrow$ 서버가 20번 포트에서 클라이언트로 역방향 데이터 접속.
  * **Passive:** 클라이언트가 `PASV` 명령 $\rightarrow$ 서버가 1024 이상 비특권 포트를 열고 클라이언트가 접속 (방화벽 친화적).

### 📌 제4과목: 정보보안 일반 (61번 ~ 80번)
* **[공식 1] 블록 암호 5대 운영 모드 완전 비교:**
  * **ECB:** IV 미사용, 동일 평문 $\rightarrow$ 동일 암호문 (가장 취약, 패턴 노출).
  * **CBC:** IV 필수, 이전 암호문과 평문 XOR 연산 후 암호화. **복호화만 병렬 처리 가능**.
  * **CFB:** IV 필수, 이전 암호문을 암호화 후 평문과 XOR (자기동기 스트림).
  * **OFB:** IV 필수, **오류 전파 없음 (해당 비트만 오류)**.
  * **CTR:** 카운터 암호화, **암호화/복호화 모두 병렬 처리 가능**, 임의 접근 가능.
* **[공식 2] 공개키 암호 알고리즘 수학적 기반:**
  * 소인수분해 문제: **RSA**, Rabin
  * 이산대수 문제: **Diffie-Hellman**, DSA, ElGamal
  * 타원곡선 이산대수: **ECC**, ECDSA (짧은 키 길이로 고강도 보안 제공)
* **[공식 3] 접근통제 3대 보안 모델:**
  * **Bell-LaPadula (BLP):** **기밀성** 보장. No Read Up (NRU), No Write Down (NWD, $\ast$-속성).
  * **Biba:** **무결성** 보장. No Read Down (NRD), No Write Up (NWU, $\ast$-속성).
  * **Clark-Wilson:** 상업적 **무결성**. 직무 분리, 잘 정의된 트랜잭션.

### 📌 제5과목: 정보보안 관리 및 법규 (81번 ~ 100번)
* **[공식 1] 정량적 위험분석 3대 산출 공식:**
  $$\text{SLE (단일손실예상액)} = \text{AV (자산가치)} \times \text{EF (노출계수)}$$
  $$\text{ALE (연간손실예상액)} = \text{SLE} \times \text{ARO (연간발생률)}$$
  $$\text{비용 효과성} = (\text{통제 전 ALE} - \text{통제 후 ALE}) - \text{보안대책비용(ACS)}$$
* **[공식 2] 재해복구센터(DRP) 4대 유형:**
  * **Mirror Site:** RTO $\approx$ 0 (실시간 이중화, 최고가)
  * **Hot Site:** RTO 수 시간 (대기 상태, 데이터 지속 미러링)
  * **Warm Site:** RTO 수 일 ~ 수 주 (중요 장비만 보유, 백업 데이터 복원 필요)
  * **Cold Site:** RTO 수 주 ~ 수 개월 (공간/설비만 확보)
* **[공식 3] 법규 핵심 수치 암기 5선 (과락 방지):**
  1. 유출 신고 기준: **1천 명 이상** 유출 시 지체 없이(**72시간 이내**) 개보위/KISA 신고.
  2. 접속기록 보관: 일반 **1년**, 5만 명 이상/고유식별정보 **2년**, 점검 주기 **월 1회**.
  3. 개인정보 파기: 사유 발생일로부터 **5일 이내**.
  4. 과징금 상한: 전체 매출액의 **3% 이하**.
  5. 징역/벌금 최빈출: **5년 이하의 징역 또는 5천만 원 이하의 벌금** (동의 없는 제3자 제공 등).

## 2. 부정형(옳지 않은 것) 60% 비중의 5대 Trap 설계 패턴

1. **[Trap 1] 대립 쌍 개념 맞바꾸기:** AH(인증/무결성) vs ESP(기밀성), `last(wtmp)` vs `who(utmp)`, 대칭키 vs 비대칭키.
2. **[Trap 2] 극성 및 방향 반전:** 전자서명 시 송신자 개인키 vs 수신자 공개키, `nocase` 옵션 의미 왜곡, 스텔스 스캔 응답 패킷 왜곡.
3. **[Trap 3] 극단어/절대화:** "반드시", "모든 경우에", "어떠한 경우에도 불가능하다" 선지는 95% 이상 오답.
4. **[Trap 4] 법령 수치 변조:** 72시간 $\leftrightarrow$ 24시간, 1년 $\leftrightarrow$ 6개월, 3% $\leftrightarrow$ 10%.
5. **[Trap 5] 관할 부처 왜곡:** 개인정보보호위원회 $\leftrightarrow$ 과기정통부 $\leftrightarrow$ 행정안전부 소관 업무 뒤섞기.

## 3. 필기 단기 고득점 공략 로드맵

* **과락 방지 (1과목 & 5과목):** umask 계산, 로그 4총사, 법령 수치 5선 완벽 암기로 55점 방어선 구축.
* **평균 견인 (2과목 & 4과목):** TCP 포트스캔 표, 블록암호 5대 운영모드, 공개키 수학적 원리로 80점 이상 확보.
* **3배속 역발상 회독법:** 1개 문제를 풀 때 정답인 오답 선지 1개의 Trap만 분석하고, **나머지 옳은 선지 3개를 요약집으로 흡수**하여 300% 압축 학습 달성.
