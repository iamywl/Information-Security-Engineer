## 🎯 Executive Summary (핵심 분석 요약)

1. **단답형(30점 만점):** 단순 암기형을 넘어 **'공식 영문 약어(Acronym) + 리눅스 절대 경로(/etc/...) + 파라미터 지시자'**의 3축 구조로 정형화되어 있으며, **IPSec, 위험분석 4대 접근법, 접근통제 모델, ISMS-P, XSS/SSRF**가 29개 회차 중 7~11회 반복 출제되어 출제율 35% 이상을 독점하고 있습니다.
2. **서술형(42점 만점):** 채점관은 문항당 14점을 3~4개의 '채점 슬롯(각 3~5점)'으로 쪼개어 키워드 매칭 방식으로 채점합니다. 따라서 **'사전 준비 $\rightarrow$ 패킷 전송/취약점 트리거 $\rightarrow$ 피해 발생/자원 고갈'의 3단계 인과관계 공식**을 적용해야만 키워드 누락에 따른 0점 폭탄을 피하고 부분점수(24~28점)를 완벽히 확보할 수 있습니다.
3. **실무형(28점 만점):** **① 웹 로그 분석(Apache Combined Log / 200 vs 404 침해 판정), ② iptables & Snort 룰셋 작성, ③ C/Java 시큐어 코딩(버퍼오버플로우/PreparedStatement), ④ 서버 보안 설정(httpd.conf / sshd_config / PAM)**의 4대 고정 패턴에서 100% 출제됩니다.
4. **합격 포트폴리오:** 기출 단답형 24점(8문항) + 서술형 부분점수 26점 + 실무형 1문항 완점 및 1문항 부분점수 18점 = **총 68점 확보**로 어떤 난이도 변동에도 60점 합격선을 안전하게 보증합니다.

## 2. 서술형 (42점 만점): 3단계 인과관계 서술 공식

* **[공식 1: 공격 원리 서술]**
  1. **(1단계 사전준비):** 공격자가 어떤 조건/조작(IP Spoofing, 페이로드 삽입)을 수행하는가?
  2. **(2단계 트리거):** 대상 시스템의 어떤 취약점 또는 프로토콜 메커니즘을 자극하는가?
  3. **(3단계 피해발생):** 대상 시스템의 자원(백로그 큐, CPU, 메모리, 세션)이 어떻게 고갈/유출되는가?
* **[공식 2: 비교 분석형]**
  * 대조군 표(Table) 또는 명확한 대구(對句) 구조로 서술 (개념, 장단점, 오탐/미탐 여부).
* **[공식 3: 보안 대책 서술]**
  * 네트워크 계층(방화벽 룰셋), 시스템/OS 계층(커널 파라미터 sysctl), 애플리케이션 계층(시큐어 코딩) 3단계 심층 방어로 서술.

## 3. 실무형 (28점 만점): 4대 핵심 실무 패턴

1. **웹 로그 분석형 (Apache Combined Log):**
   * 클라이언트 IP, 타임스탬프, 요청 Method/URI, **HTTP 상태 코드(200 vs 404 침해 여부 판정)**, 응답 크기, User-Agent 분석.
2. **방화벽 및 IDS 룰셋 작성형:**
   * `iptables -A INPUT -p tcp --dport 80 -m recent --name SYN_DROP --update --seconds 2 --hitcount 30 -j DROP`
   * `alert tcp $EXTERNAL_NET any -> $HTTP_SERVERS 80 (msg:"WEB-ATTACK /etc/passwd"; content:"/etc/passwd"; nocase; sid:1000001; rev:1;)`
3. **C/Java 시큐어 코딩형:**
   * C 버퍼오버플로우 대체: `strcpy` $\rightarrow$ `strncpy(buff, src, sizeof(buff)-1); buff[sizeof(buff)-1] = '\0';`
   * Java SQL Injection 방어: `PreparedStatement pstmt = con.prepareStatement(sql); pstmt.setString(1, gubun);`
4. **서버 및 시스템 보안 설정형:**
   * Apache: `Options -Indexes`, `ServerTokens Prod`, `ServerSignature Off`, `LimitRequestBody 5242880`
   * SSH: `PermitRootLogin no`, `Protocol 2`, `Port 2222`
   * BIND DNS: `allow-transfer { none; };`, `recursion no;`
