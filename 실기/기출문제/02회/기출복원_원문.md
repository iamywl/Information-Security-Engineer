# 정보보안기사 실기 제2회 기출복원

* **시험 구분:** 국가기술자격 정보보안기사 실기
* **문항 수:** 총 8문항
* **출처:** 수험생 커뮤니티 복원 데이터

---

### 1번 [단답형]

리눅스 PAM(Pluggable Authentication Module)의 모듈 인터페이스 유형 4가지 중 다음에 해당하는 것을 각각 기술하시오.
(A) 패스워드 등 인증 정보를 입력받아 신원을 확인하는 모듈
(B) 계정의 유효 기간, 접근 시간, 비밀번호 만료 등을 검사하는 모듈
(C) 로그인 전후 사용자 환경 설정 및 마운트 작업을 수행하는 모듈

> **정답:** (A) auth, (B) account, (C) session

> **해설:** PAM 4가지 모듈 타입: auth(인증), account(계정 유효성), password(비밀번호 갱신), session(세션 개설/종료).

### 2번 [단답형]

Windows 운영체제의 대표적인 저널링 파일 시스템으로, 사용자별 파일/폴더 접근 권한 설정(ACL), 파일 암호화(EFS), 대용량 볼륨 지원을 제공하는 파일 시스템은 무엇인가?

> **정답:** NTFS (New Technology File System)

> **해설:** FAT32와 달리 NTFS는 보안 권한 설정 및 트랜잭션 저널링을 지원합니다.


---

### 3번 [단답형]

메시지 발신자부터 수신자까지의 통신 경로에서 중간 서버나 중계자가 평문 데이터에 접근할 수 없도록 양 끝단에서만 암호화 및 복호화를 수행하는 방식을 무엇이라 하는가?

> **정답:** 종단 간 암호화 (E2EE, End-to-End Encryption)

> **해설:** TLS 구간 암호화와 달리 중간 프록시나 서비스 제공자 서버에서도 데이터를 열람할 수 없습니다.


---

### 4번 [단답형]

엔드포인트 에이전트와 네트워크 모니터링을 통해 기밀 문서가 USB, 이메일, 메신저 등을 통해 외부로 유출되는 것을 사전에 탐지하고 차단하는 정보보호 솔루션은 무엇인가?

> **정답:** DLP (Data Loss Prevention, 정보유출방지)

> **해설:** 중요 기밀 정보(개인정보, 소스코드 등)의 반출 경로를 감시 및 통제합니다.

### 5번 [단답형]

C 언어에서 버퍼 크기 검증 없이 메모리에 데이터를 복사하여 반환 주소(RET)를 변조할 수 있는 대표적인 취약점 명칭과, 이에 취약한 위험 함수 2가지를 기술하시오.

> **정답:** 취약점: 버퍼 오버플로우 (Buffer Overflow), 함수: strcpy, gets, sprintf 등

> **해설:** 안전한 함수(strncpy, fgets, snprintf 등)를 사용하거나 스택 보호 기법(Canary, ASLR, DEP)을 적용해야 합니다.

### 6번 [단답형]

리눅스 시스템에서 계정의 암호화된 비밀번호와 만료일 등의 정보를 보관하며, root 권한(0640 또는 0600)으로만 열람 가능한 핵심 보안 설정 파일의 경로는 무엇인가?

> **정답:** /etc/shadow

> **해설:** /etc/passwd에 패스워드 해시가 있던 보안 문제를 해결하기 위해 섀도 패스워드 시스템이 도입되었습니다.

### 7번 [서술형]

SQL Injection 공격의 기본 원리를 설명하고, 개발 단계에서 이를 원천 차단하기 위한 PreparedStatement(파라미터화된 쿼리)의 방어 원리를 서술하시오.

> **정답:** 원리: 사용자 입력값을 검증 없이 동적 SQL 쿼리 문자열에 연결(Concatenation)할 때, 공격자가 입력한 따옴표(')나 SQL 연산자(OR 1=1 등)가 쿼리 문법으로 해석되어 실행됨.
방어 원리: PreparedStatement는 쿼리 구문 구조를 데이터베이스 엔진에 사전 컴파일(Pre-compile)한 뒤, 사용자 입력값을 단순한 리터럴 데이터(바인딩 변수)로만 취급하므로 입력값에 SQL 문법 요소가 포함되어도 코드로 해석되지 않고 텍스트로 안전하게 처리됨.

> **해설:** 시큐어 코딩의 가장 핵심적인 조치 항목입니다.

### 8번 [실무형]

아파치 웹서버(httpd.conf) 설정에서 디렉터리 리스팅 취약점을 제거하고, 서버 버전 정보 노출을 최소화하기 위한 설정 지시자 2가지를 작성하시오.

> **정답:** 1) 디렉터리 리스팅 방지: Options -Indexes
2) 서버 정보 노출 차단: ServerTokens Prod, ServerSignature Off

> **해설:** 정보 수집(Reconnaissance) 공격을 차단하는 웹서버 보안 조치입니다.
