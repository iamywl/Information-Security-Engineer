### 2번 [단답형]

```text
1. 사용자는 q.fran.kr 사이트에 접속을 시도한다.
2. 공격자는 캐시 DNS 서버가 DNS 서버로부터 정상 DNS 응답을 받기 전 조작된 DNS 응답을 보낸다.

4. 사용자는 조작된 주소의 사이트로 접속하게 된다.
```

### 11번 [단답형]

다음에서 설명하는 것을 각각 쓰시오.

```text
(1) 가명정보의 정의를 쓰시오.
(2) 다음은 가명처리 단계이다. 괄호안에 들어갈 단계를 쓰시오.
 사전준비 → 가명처리 → ( 괄호 ) → 사후관리
(3) 가명정보를 정보주체 동의 없이도 활용 가능한 경우를 3가지 쓰시오.
(4) 가명정보를 사용할 필요가 없을 때 개인정보보호법에 해당되지 않는 ( 괄호 )를 사용해야 한다. 괄호안에 들어갈 말은?
```

> **정답:** (1) 가명정보 : 개인정보를 가명처리함으로써 원래의 상태로 복원하기 위한 추가 정보의 사용 · 결합 없이는 특정 개인을 알아볼 수 없는 정보 
(2) 적정성 검토 및 추가처리 
(3) (1) 통계작성 (2) 과학적 연구 (3) 공익적 기록보존 
(4) 익명정보

### 14번 [단답형]

다음 웹 로그를 보고 알맞은 내용을 쓰시오.

```text
192.168.0.11 192.168.0.30 get /script/..%c0%80%ef../winnt/system32/cmd.exe?/c+dir 404 420 324 HTTP 1.0

(1) 어떤 취약점을 이용한 공격 시도인가?
(2) 공격 성공 유무 및 이유를 쓰시오.
(3) 대응 방안을 2가지 쓰시오.
```

> **정답:** (1) 웹서버 폴더 통과 취약점(Web Server Folder Traversal, CVE-2000-0884) 
(2) 실패. 404로 파일의 정확한 위치를 파악하지 못함 
(3) 아래 중 2가지 이상  
1. 정해지지 않은 폴더에 접근할 수 없도록 퍼미션 설정 
2. 이상 입력값을 입력하지 못하도록 에러처리 
3. IIS 서버 패치

### 15번 [단답형]

각각의 Snort Rule 설정의 의미를 작성하시오.

```text
(1) msg:"GET Flooding"
(2) content:"GET / HTTP1."
(3) content:"USER"; content:!"anonymous"
(4) content:"|00|";depth:1
```

> **정답:** (1) alert 발생 시 GET Flooding이 이벤트 이름으로 사용된다. 
(2) GET / HTTP1. 문자열을 검사한다. 
(3) 문자열이 USER을 포함하고 anonymous를 포함하지 않는지 검사한다. 
(4) 1바이트의 바이너리 값이 00인지 검사한다.

### 16번 [단답형]

다음과 같이 Apache 설정 시 발생할 수 있는 문제점 두가지를 작성하고 대응 방안을 쓰시오.

```text
Options FollowSymLinks
AllowOverride none
Require all granted



Options indexes FollowSymLinks
AllowOverride none
Require all granted




(1) 발생하는 두가지 문제점
(2) 두가지 문제점에 대한 대응방안
```

> **정답:** (1)  
1. 디렉터리 리스팅으로 웹 서버 구조 및 중요 파일 노출됨. 
2. 상위 디렉터리로 이동하여 악의적인 접근 가능함. 
 
(2) 
1. /var/www 디렉터리의 Options 지시자에서 Indexes 옵션 제거 
2. AllowOverride 옵션을 None -> AuthConfig로 변경
