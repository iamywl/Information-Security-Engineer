# 정보보안기사 실기 제작문제

최신 출제 경향을 반영한 자체 제작 실기 연습문제 세트입니다.

## 구성
1. **단답형 훈련:** 최신 보안 용어(Zero Trust, SBOM, MITRE ATT&CK 등) 및 필수 명령어
2. **서술형 훈련:** 취약점 분석 및 공격 시나리오 대응 절차
3. **실무형 훈련:**
   * Apache/Nginx 웹서버 보안 설정 및 로그 분석
   * Snort / Suricata IDS 탐지 룰셋 작성
   * iptables / firewalld 패킷 필터링
   * C/Java/Python 시큐어 코딩 (SQL Injection, XSS, Buffer Overflow 방어)
