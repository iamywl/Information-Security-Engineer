# 🛡️ 정보보안기사 실기 자작문제 아카이브

2024~2026년 최신 출제 경향을 반영한 고난도 실전 모의고사 세트입니다.  
채점관의 **키워드 매칭 기준**과 **3단계 인과관계 서술 공식**에 맞추어 제작되었습니다.

---

## 📂 실기 자작문제 모음
* **[2026 최신 트렌드 실기 실전 모의고사 세트](2026_최신트렌드_실기자작문제.md)**
  1. **단답형 (각 3점):**
     * 제로 트러스트 아키텍처(ZTA) 정책 결정 포인트(PDP) 및 정책 시행 포인트(PEP)
     * 소프트웨어 자재명세서(SBOM) 및 공급망 보안
     * 생성형 AI 프롬프트 인젝션(Prompt Injection)
  2. **서술형 (14점):**
     * 검색 증강 생성(RAG) 환경의 간접 프롬프트 인젝션(Indirect Prompt Injection) 동작 원리 3단계 및 방어 대책 2가지
  3. **실무형 (14점):**
     * Docker 컨테이너 탈출 방지 보안 기동 설정(`--security-opt no-new-privileges`, `--read-only`, `--cap-drop=ALL`)
     * iptables의 `recent` 모듈을 활용한 SSH 무차별 대입 공격(Brute Force) 60초 5회 초과 차단 룰셋 작성
