# 정보보안기사 실기

정보보안기사 실기 시험 대비를 위한 아카이브 및 학습 플랫폼입니다.

## 시험 구성 (총 16~18문항, 180분)
1. **단답형 (10문항, 문항당 3점, 총 30점):**
   * 보안 용어, 리눅스/윈도우 명령어, 프로토콜, 법령 기준 키워드 기입
2. **서술형 (3문항, 문항당 14점, 총 42점):**
   * 공격 기법 원리 분석, 보안 정책 수립, 취약점 조치 방안 서술
3. **실무형 (3문항 중 2문항 선택, 문항당 14점, 총 28점):**
   * 서버 보안 설정(iptables, Snort 룰, Apache/Nginx 설정 등), 침해사고 로그 분석, 소스코드 보안 약점 진단

## 디렉토리 안내
* `기출문제/` : 역대 회차별 복원 기출문제 (단답형, 서술형, 실무형) 및 해설
* `제작문제/` : 자체 제작 실기 연습문제 (로그 분석, 실습형 모의고사)
